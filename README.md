## About

Hi, I'm **Ansh Priyadarshi**, a student at **Coding Gita** building a foundation in software development. I learn by exploring new ideas, making small projects, debugging, and improving them step by step.

I'm interested in how programming, web development, and design can come together to make useful things.

## What I'm learning

- **Programming:** Python and JavaScript
- **Web:** HTML and interactive web experiences
- **Design:** Figma and interface design
- **Workflow:** Git, GitHub, and VS Code

These are areas I'm learning and using, not claims of mastery.

## My approach

> Stay curious. Build small. Learn from what breaks. Keep improving.

I want to understand why things work, not only memorize syntax. I'm exploring web and application development, data structures and algorithms, AI/ML, and UI/UX as possible next directions.
